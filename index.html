Create an app at developer.spotify.com/dashboard, then add this exact redirect URI to it: Playback control requires Spotify Premium, and Spotify must be open on some device — this page steers that device, it does not play audio itself.
Playback device
Pick the device the drill sheet should steer, or it follows whichever Spotify was last active — often the wrong one. A device only appears here while its Spotify app is running, so open Spotify there first, then Refresh.
Transfer a connection
For a browser too old to show Spotify's login page. Connect on a modern browser pointed at this same address, copy the code it produces, and paste it here.
The code contains a login token for your account — treat it like a password. Send it to yourself privately and don't publish it with the bundle.

Once, for everyone

        
    
          
  1. Create an app at developer.spotify.com/dashboard and tick Web API.
    2. 
          
  2. Add this exact redirect URI to it: 
    3. 
          
  3. Under User Management, add every rider — full name plus the email on
              their Spotify account. Without this their login succeeds but all playback
              returns 403.
    4. 
          
  4. Each rider needs Spotify Premium.
    5. 
        

      


      

        
💻 Laptop — get the token once per rider

        

          The iPad's Safari is too old to show Spotify's login page, so authorising happens here.
        

        
    
          
  1. Open the drill sheet at the same address the iPad uses — the redirect URI
              comes from the address, so a different one won't match.
    2. 
          
  2. Open ♫ Spotify. The environment line must be green.
    3. 
          
  3. Type the rider's name into Name for a new connection, press Connect,
              sign in as that rider and approve.
    4. 
          
  4. Press Copy code from this device and send the code to yourself privately.
    5. 
          
  5. Press Sign out on the laptop.
    6. 
        

        

          Step 5 matters: Spotify rotates these tokens, so two devices holding the same one
          will sign each other out. The iPad should be the only holder.
        

      


      

        
📱 iPad — the controller once per rider

        
    
          
  1. ♫ Spotify → Transfer a connection. Enter the rider's name, paste
              the code, press Add connection. The Client ID comes along with it.
    2. 
          
  2. On that rider's iPhone, open Spotify and play anything for two seconds
              (see below), then come back.
    3. 
          
  3. Select the rider in Connection, then under Playback device
              press ↺ Refresh and pick their iPhone.
    4. 
        

        

          Each rider keeps their own playback device — Spotify devices belong to an account,
          so they can't be shared between connections.
        

      


      

        
🎵 iPhone — the player

        
    
          
  1. Open the Spotify app, signed in as that rider.
    2. 
          
  2. Play any track for two seconds, then pause. Nothing registers as a
              Spotify Connect device until it has actually played something.
    3. 
          
  3. Connect it to your speaker if you're using one — a Bluetooth speaker is the
              phone's output, not a separate device, so pick the iPhone on the iPad.
    4. 
          
  4. Don't swipe Spotify closed. Backgrounded and screen-locked are both fine.
    5. 
        

      


      

        
Before each class

        
    
          
  1. Make sure that iPhone's Spotify has played something recently.
    2. 
          
  2. On the iPad, pick the drill sheet — the Ready to ride dialog opens.
    3. 
          
  3. Choose the Rider, check the Speaker, set subtask progress,
              read the Playlist check, then Let's go.
    4. 
          
  4. Press Start.
    5. 
        

      


      

        
When something's wrong

        

          
Red environment linePage isn't HTTPS, or it's the wrong address

          
Spotify error page after ConnectRedirect URI doesn't match the registered one exactly

          
Login works but playback 403Rider not on the app's allowlist, or no Premium

          
"Could not read the playlist: forbidden"Connected before playlist access was requested — reconnect that rider

          
iPhone missing from the device listPlay something on it, then ↺ Refresh

          
Music on the wrong deviceWrong rider selected, or the chosen device went offline

          
Rider shows "(needs sign-in)"Paste the saved code again; if refused, redo the laptop steps

          
Saved code refusedIt went stale when the iPad refreshed — copy a new one from the iPad
